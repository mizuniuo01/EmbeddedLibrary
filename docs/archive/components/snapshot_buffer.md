# snapshot_buffer

两个静态数据槽，写事务与读借用显式登记，禁止复用仍被借用的槽。

## 公共边界

所属层级：Libraries；唯一组件依赖为 `foundation_status`，使用标准 C11。
实例由调用方以 `{0}` 初始化并提供静态存储，字段仅供实现使用；实例初始化后禁止按值复制。
所有传入指针必须指向存活对象，所报长度不得超过真实对象大小。C 无法检测悬空指针或虚报容量。
存储和输出区不得与实例、内部存储或同次其他输出重叠；重叠检查在任何复制之前完成。
失败不写普通输出，不改变有效数据；只有明确的饱和诊断计数可在容量不足时改变。
成功重新初始化会清空逻辑内容及统计，失败保持旧绑定；实例及存储均由调用方拥有，不释放内存。

同一实例的全部 API（包括查询）必须由调用方串行化。不同实例使用不重叠存储时可重入。
没有内置锁、等待、超时、回调或任务创建，不保证直接用于 ISR/任务并发；
P3 才实现 RTOS 同步适配。主机测试不替代目标 MCU 原子性、WCET、DMA/cache 或上板验证。

内存区间检查是明确的 ABI 边界：依赖目标提供 `uintptr_t`，对象地址转换后保序，
字节地址差对应对象内字节距离。当前验证目标为 Linux GCC/Clang 和 ARM GCC 的平坦地址 ABI。
不适用于未经验证的分段地址或特殊指针平台；不依赖主机字节序。
内存函数采用标准 C11，长度及不重叠已预检；仅相应调用局部抑制 Annex K 建议，
不要求可选 `memcpy_s/memset_s`，不关闭全局分析规则。

## 生命周期与状态

`init(buffer, first, second, capacity)` 要求两个不重叠的等容量槽，容量非零。
首次使用前实例必须为 {0}。存在写事务或读借用时重绑返回 BUSY。
成功重绑清除发布状态和序号；无堆、无读者链表。

- `begin(buffer, writer)` 借出未发布或非活动且无人借用的槽，writer 返回可写地址和容量。
  正在写入或候选槽被借用时 BUSY；原快照保持可读。begin 不复制旧数据、不清零载荷。
- `publish(buffer, writer, size, timestamp)` 要求同一 writer 对象，且 size <= capacity。
  调用者必须已写完这 size 字节；发布后 writer 清空，旧可写指针立即失效。
  第一帧 sequence 为 1，随后由库递增；到 UINT32_MAX 后返回 OVERFLOW，禁止静默回绕。
  timestamp 为调用方提供的 uint32_t 单调 tick，单位由使用者统一；库不读系统时钟、不验证时间顺序。
  size == 0 合法。长度或序号失败保留写事务，可修改后重试或 cancel。
- 当前活动槽可以仍被读者借用：publish 切换到已获准的写槽，不修改旧槽。
  是否有可用写槽由 begin 决定，不在完成写入后无故拒绝 publish。
- `cancel` 归还写槽并清空 writer，原快照和元数据不变；非活动槽已写字节不回滚。
- `acquire(buffer, lease)` 返回 const 数据、长度、sequence、timestamp，并登记 lease 原地址。
  未发布为 EMPTY；当前槽已有读借用为 BUSY。每槽最多一个读借用，共最多两个；
  更多消费者使用 copy 或等待并串行借用，不假设多个消费者同时结束。
- `release` 要求原地址的、字段未改的 lease；成功清空 lease，重复或复制凭据返回 INVALID_STATE。
  借用凭据在归还前必须保持存活且不得复用于另一实例。其地址身份用于检测凭据复制，
  不是内存安全能力；C 无法阻止调用者保留归还后的裸指针或越界写。
- `copy(buffer, data, capacity, info)` 一次复制有效长度及对应元数据。
  不占用借用名额，可在已有只读借用时调用；容量不足不复制任何数据。
  空帧允许 NULL + 0；输出区、元数据与内部资源及现存凭据不得重叠。
- `sequence/timestamp` 查询当前帧，未发布返回 EMPTY；需要成对一致时用 copy/acquire 的元数据。

读借用是防复用协议，不是锁。所有 API 调用必须外部串行化，跨线程发布需互斥或临界区的
内存可见性保证。acquire 后可在锁外读取，因为库保留槽；读取完毕再加锁 release。
写者 begin 后可在锁外填充自己独占的槽，完成后加锁 publish。不得在同一读/写凭据上并发操作。
这里的发布切换只在外部同步保护下是逻辑原子操作，不使用 C 原子类型或声称无锁安全。

## 资源、恢复与验证

RAM 为 sizeof(snapshot_buffer_t) + 2 × capacity，外加调用方最多两个读凭据、一个写凭据。
元数据/借用 API O(1)，copy O(有效长度)，栈 O(1)。
读者长期不 release 会产生持续 BUSY；库不强行撤销仍在使用的内存，没有借用超时自动回收。
序号耗尽后取消写事务、归还全部读借用再重新初始化；新实例周期由上层识别。
测试覆盖写事务失败原子性、旧视图跨发布稳定、两槽借用背压、重复/复制凭据、
取消、空帧、长度和序号溢出、元数据一致性与重叠。
证据见 [P1 阶段计划](../plans/P1_FOUNDATION.md)；RTOS 调度、TSan 和上板 WCET 不在本批证据内。
