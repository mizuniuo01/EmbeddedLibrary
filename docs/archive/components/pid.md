# pid

所属层级：Libraries。职责：提供与时钟、任务和执行器无关的单精度 PID 计算。

第一批仅实现 f32。调用者显式提供正有限 `dt`；算法不读取系统时间。实例由调用者静态分配，
初始化后不得按值复制。配置、输入和中间结果非法时返回状态码，保持历史状态和输出不变。

支持对误差或测量值求导；支持条件积分和回算抗饱和。输出与积分状态分别使用闭区间限制。
`reset` 清除积分并同步历史值，避免首次计算产生人为导数冲击。不存在动态内存、RTOS 类型、
执行器写入或产品控制模式。

测试覆盖未初始化、reset、显式 dt、两种导数模式、两种抗饱和模式、输出限幅、NaN、非法 dt、
非法配置和失败输出保持。当前成熟度为 `host-tested / hardware-unverified`。
