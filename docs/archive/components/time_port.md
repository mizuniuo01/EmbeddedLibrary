# time_port

所属层级：Services。职责：为需要单调时钟的组件提供可替换的 32 位或 64 位时间能力。

32 位时间遵守 `tick32` 的模回绕和半范围规则；64 位读数必须由适配器保证单调且一致。端口记录
tick 频率和 ISR 可调用性。`sleep_until` 接收绝对 deadline，不提供永久等待；适配器不支持阻塞时
返回 `UNAVAILABLE`，真正等到期限才返回 `TIMEOUT`。

函数表和 context 在全部调用结束前保持有效，初始化后只读。组件不拥有时钟、不使用堆，也不从
32 位 tick 隐式扩展 64 位时间。测试 fake 使用手动时钟，不依赖真实 sleep。
