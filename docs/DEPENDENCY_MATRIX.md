# 能力与成熟库评估矩阵

本表用于 R0。已完成实现仍需评估，但在结论确认前不删除、不替换。

| 能力 | 当前资产 | 候选成熟库 | 结论 | 依据/风险 |
| --- | --- | --- | --- | --- |
| 时间数学、状态码 | P1 | 待调查 | 待定 | 需保持现有 API 与无平台依赖 |
| FIFO、队列、对象池、快照 | P1/P3 | 待调查 | 待定 | 重点比较静态容量、并发和 M0 资源 |
| CRC、字节序、COBS/SLIP | P1 | 待调查 | 待定 | 优先复用成熟实现并保持边界校验 |
| PID 与滤波算法 | P2 | 待调查 | 待定 | 需比较数值行为、许可证和测试覆盖 |
| 并发端口与 waiter | P3 | 待调查 | 待定 | 核心接口需隔离 RTOS 类型 |
| 协作式调度器 | 无 | 不预设 | 自研 | 属于本仓库架构核心 |
| 日志、错误、诊断 | 无 | 待调查 | 待定 | 需结构化记录、固定容量和 sink 隔离 |
| 参数与存储 | 无 | 待调查 | 待定 | 需类型化 API、版本和完整性 |
| 通信与协议 | 无 | 待调查 | 待定 | 按传输、帧、会话和命令边界评估 |
| 菜单与蓝牙 | 无 | 待调查 | 待定 | 不得绑定显示或具体芯片 |

候选依赖必须记录源码来源、锁定版本、许可证、维护状态、资源预算、规范差距、适配职责和验证平台。
