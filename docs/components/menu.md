# mizu_menu 组件说明

`mizu_menu` 属于 Services 层，是 parameter 和 command 公共能力之上的硬件无关调试菜单编排服务。S8 已完成导航、参数、命令、展示页和语义视图查询。

## 分层和依赖

- menu 直接依赖 parameter 和 command 公共 API，作为本仓库明确登记的 Services 横向编排例外。
- parameter 和 command 不得反向依赖 menu。
- Domain 提供菜单组、条目顺序和展示页描述；Application/Composition Root 创建实例并绑定适配器。
- 菜单不依赖 BSP、Driver、HAL、RTOS、OLED、LCD、蓝牙或具体编码。

### 架构例外登记

- 例外方向：`Services/menu` 只允许调用 `Services/parameter` 和 `Services/command` 的公共 API。
- 允许用途：读取稳定描述符、读取和提交参数、执行已注册命令；不得访问依赖服务的私有字段或内部状态。
- 反向约束：parameter 和 command 不得依赖 menu；menu 不得把横向依赖继续传递到 BSP、Driver、HAL、RTOS 或具体输入输出实现。
- 例外理由：menu 是调试交互的横向编排服务，必须把导航状态与参数/命令语义组合成统一视图；将这些调用拆成项目端口会重复定义同一套描述符和操作协议。
- 生命周期和并发：三个服务均由 Composition Root 静态持有并在装配阶段初始化；运行期只允许在同一主循环或已同步的普通任务上下文串行调用。
- 验证证据：menu 单元测试覆盖描述符查询、容量不足、视图预检和 getter 失败；静态检查确认不存在反向 include 或硬件依赖。

## 所有权和生命周期

- 调用方静态持有菜单实例、根描述表、组/条目表、文本和运行期步长缓存。
- menu 只借用这些对象，不分配、不释放，也不建立隐藏固定容量。
- 每个输出交互通道使用独立菜单实例；多个实例可共享 parameter/command，但调用方必须串行访问共享服务。
- `mizu_menu_init()` 在装配阶段只允许一次成功调用；已初始化对象再次 init 应返回 `MIZU_STATUS_INVALID_STATE` 并保持旧菜单状态、绑定和 step cache。当前实现尚待修复，见 `REVIEW-S8-001`。运行期不支持 reset、deinit 或重新注册。
- 一个 menu 实例对应一个交互/输出通道；不同屏幕或蓝牙会话使用独立实例和独立 step cache。

## 输入和输出边界

- 输入适配器负责按键消抖、长按、连发、编码器解码和蓝牙协议解析，只向 menu 提交逻辑事件。
- 输出适配器负责可见数量、坐标、字体、编码、光标外观和最终输出。
- menu 的组件只表达选择、编辑、确认和强类型参数值等语义，不表达像素或具体控件外观。
- 展示页只由 menu 维护 ID、标题和子页导航；实时数据仍由生产模块拥有，适配器直接调用其查询 API。
- root/group/item/display-page 描述在装配阶段固定，运行期不注册、删除或修改。

## 第一批初始化契约

- 根列表是 Domain 提供的有序数组，元素为参数/命令混排组或外部展示页。
- 菜单组显式引用 parameter/command 稳定 ID；名称、单位、类型和默认步长来自服务描述符。
- 菜单参数必须可写；只读实时值由展示适配器负责。
- 调用方步长缓存数量必须等于 parameter 注册参数总数，初始化按注册顺序复制默认步长。
- 任何初始化错误都不修改菜单对象或调用方步长缓存。
- 所有接口只允许在主循环或已同步的普通任务上下文串行调用，不支持 ISR、并发或重入。

## 第二批参数交互

- 根列表和组内列表均按有符号增量循环移动；输入适配器可把编码器累计量直接作为移动量。
- 激活可写 parameter 条目时读取当前值并建立菜单私有草稿；调整事件只修改草稿。
- 每个参数的运行期步长由调用方缓存保存，步长编辑按十倍档缩放；确认保留，取消恢复。
- step cache 属于 menu owner/实例，不属于 parameter service；每个 menu 实例使用独立缓存。
- 提交前重新读取真实值；发现外部修改时重载当前值并保留编辑状态，不覆盖外部更新。
- 参数读取、提交和冲突通过限时 feedback 报告；成功提交后回到原组列表。
- `process()` 仅按调用方传入的单调时间清除到期 feedback，不读取硬件时钟。

## 第三批命令和展示页

- 命令绑定可声明是否需要确认；无需确认的命令激活后执行一次，需要确认的命令再次激活才执行。
- 命令 handler 始终同步调用一次；`MIZU_STATUS_BUSY` 只作为本次结果反馈，不自动轮询或保存活动命令。
- OK、BUSY 和错误统一写入限时命令 feedback；菜单立即回到原组列表，后续输入不受阻塞。
- 展示页从根列表进入，按有符号页增量循环切换子页，返回时回到原根位置。
- menu 只保存展示页 ID 对应的导航状态，不读取或保存状态/实时数据。
- 展示页查询只返回 page 元数据；实时数据由 Domain 或输出适配器查询和格式化。

## 第四批语义视图

- 当前组件类型只有根项目、参数、命令、参数编辑器和命令确认；未实现的文本、通用值和通用状态组件不属于当前公共接口。
- `query_view()` 按当前导航上下文返回根列表、组列表、参数编辑器、命令确认或展示页元数据。
- 适配器每次提供可见条目数量和固定组件数组；菜单计算页码、选中标志和当前页组件。
- 基础参数错误或菜单未初始化时不承诺输出；容量不足或描述符预检失败时，view 保留当前页面元数据和所需数量，组件数组不写入。
- 只有返回 `MIZU_STATUS_OK` 时组件数组有效；容量不足返回 `MIZU_STATUS_OUT_OF_RANGE`，描述符错误原样传播。
- 根列表和组列表在写入组件数组前先预检当前页所有描述符。
- 参数 getter 失败只标记对应组件的 `value_status`，不让单个实时读取失败破坏整页快照。
- 展示页查询只返回页面 ID、标题、当前子页和子页总数；实际状态/实时数据由适配器从外部数据源查询。

## 输入适配边界

- 原始按键、消抖、长按、连发、旋转编码器解码和蓝牙协议解析属于 menu 外部的输入适配器。
- menu 只接收 `mizu_menu_event_t` 逻辑事件，不读取硬件、不解析协议。
- command 返回 `MIZU_STATUS_BUSY` 时 menu 只记录 feedback，不阻塞、不轮询，立即回到普通菜单状态。
